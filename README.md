# Android Development — Linux Packages

Offline-bundled Linux packages for [android-development](https://github.com/mvaliolahi/android-development).

This repo is automatically fetched by `install.sh` on Linux machines.
You do not need to clone it manually.

## Contents
- JDK 17.0.17 (Eclipse Temurin, Linux x86_64)
- Android NDK r28 (Linux)
- Android SDK Command-line Tools 13.0 (Linux)
- Android Platform Tools (Linux)
- Android Emulator (Linux)
- CMake 3.22.1 (Linux)
- Android Studio Quail4 2026.1.4 (Linux)
